# 指数比較と自動売買システムの評価

評価日：2026年10月24日。前回試算と条件を揃え、価格の評価基準日は **2026年10月22日終値** に固定した。運用開始予定日は2021年10月23日、2025年10月23日、2026年4月23日で、休日なら次の各市場営業日の始値から参加する。すべて初期100万円・積立なし。

結論は、**現状の戦略は指数に対する優位性を示していない。6銘柄の少なさだけでなく、低い資金稼働率と銘柄偏重、検証モデルの不備を先に直す必要がある**。5年の低い下落幅には長所があるが、そのまま「高リスクでも安全」と判断する根拠にはならない。

## 同期間の指数との比較

| --- | ---: | ---: | ---: |
| 5年前 | 1,453,336円（+45.33%） | 2,341,297円（+134.13%） | 2,205,193円（+120.52%） |
| 1年前 | 970,335円（−2.97%） | 1,189,651円（+18.97%） | 1,287,339円（+28.73%） |
| 半年前 | 993,134円（−0.69%） | 1,067,353円（+6.74%） | 1,052,699円（+5.27%） |

指数は最初の取引日の始値で全額投資し、期末終値で評価する価格指数の参考値。指数自体を購入できるという意味ではなく、端数・単元制約、投信/ETFの売買費用・信託報酬・追随誤差は含まない。指数は配当なし・費用なし、現戦略は前回同様に配当なし・売買/為替費用/スリッページ込み。実運用の採否では配当と費用を揃えた投資可能商品でも比較すべきである。

S&P500は米ドル建て指数をドル円で円換算した為替ヘッジなしの参考値。5年の米ドル建て上昇は68.29%、円換算では134.13%で、円安の効果も大きい。円換算は前回モデルと同じ日別ドル円終値を使用し、後述の時刻の近似がある。

| 期間中の最大下落率 | 現戦略 | S&P500・円換算 | 日経平均 |
| --- | ---: | ---: | ---: |
| 5年 | −7.35% | −23.52% | −26.26% |
| 1年 | −6.39% | −7.88% | −15.11% |
| 半年 | −4.38% | −6.17% | −15.11% |

現戦略は収益で負ける一方、日次評価上の下落幅は小さい。これは大部分が現金だったことも含めた結果であり、満額投資の指数との比較だけでリスク調整後の優劣は決められない。日米の時差も日付単位で扱っており、日次下落率は精密な同時点評価ではない。

## 現金比率と単純な代替案

| 期間 | 現戦略の平均株式比率 | 期末株式比率 | 全額現金だったデータ日の割合 |
| --- | ---: | ---: | ---: |
| 5年 | 19.42% | 22.71% | 25.33% |
| 1年 | 12.53% | 19.84% | 34.23% |
| 半年 | 18.44% | 19.39% | 14.50% |

平均は履歴内の各データ日終値における株式評価額/口座総額の単純平均。現金利息は0。株式上限90%は投資目標ではない。現在のルールと銘柄では、上限まで買う設計にはなっていない。

単純な低稼働率の参考として、開始時に「S&P500円換算15%・日経平均15%・現金70%」を買い、そのまま保有した場合も計算した。株式の値上がりで比率は変わり、30%を維持するリバランスはしない。現戦略と同じリスクに厳密に調整した比較ではなく、費用なしの参考例である。

| 期間 | 現戦略の収益 / 最大下落 | 初期株30%・現金70%の収益 / 最大下落 |
| --- | ---: | ---: |
| 5年 | +45.33% / −7.35% | +38.20% / −9.30% |
| 1年 | −2.97% / −6.39% | +7.15% / −3.15% |
| 半年 | −0.69% / −4.38% | +1.80% / −2.73% |

5年だけなら現戦略がこの参考例より高収益・小さい下落だが、最近1年と半年は両指標で劣る。選択バイアスや時刻の問題を含むため、5年の結果から優位性を認定できない。次段階では、同程度の平均株式比率・実現変動率を持つ指数＋現金を複数用意し、未使用期間で評価する。

## 対象銘柄は足りるか

この6銘柄では日米株戦略としての一般性を検証するには不足している。S&P500は米国の主要約500社、日経平均は東証プライムの225銘柄を対象とするが、現在の戦略で実際に取引したのは5年で4銘柄、最近1年・半年はAAPL/MSFT/NVDAの3銘柄だけ。米国部分は同種のテック関連企業に偏る。

5年の総利益453,336円のうちNVDAの利益は278,692円、約61.5%。対象銘柄数だけでなく、利益・業種・国・通貨・共通要因への集中を評価すべきである。NVDAを除外する検証は有効だが、単純に利益を引くのではなく、余力や他の数量も変わるため再実行が必要。

資金100万円に対する新規購入予算は、高リスクでも概算 `100万円×(2%÷15%)×0.97＝129,333円`。日本株100株なら株価約1,293円以下が初期の目安になる。トヨタ・ソニーはこの予算と単元の関係で取引されなかった。監視リストに名前があっても、投資可能な対象になっていなかった。

改善案は「当時の日経225/S&P500構成銘柄など、事前定義した複数業種の集合から、流動性・売買単位・予算で投資可能な候補を選ぶ」こと。ETFを候補に含める案も評価する。現在の構成銘柄を過去にそのまま当てはめず、当時の構成・新規上場・上場廃止も反映する。監視候補は多くても全銘柄を保有する必要はなく、保有数・業種上限は未使用データで評価して決める。銘柄を増やせば自動的にリターンが上がるとは言えない。

## 問題と対策の優先順位

| 優先 | 問題 | 対策と完了・採用基準 |
| --- | --- | --- |
| P0 | **為替と日米市場の時刻に未来情報が混じる。** 同日為替終値を寄り付き約定に使う。日本市場寄り付きの上限判定で、同日の後刻の米国始値も評価に使う構造。 | UTC時刻順の市場イベント処理へ変更。注文・余力判定にその時点で確定済みの価格と為替だけを使い、執行用と評価用のレートを分離。未来の為替や他市場価格を書き換えても、それ以前の注文・約定が変わらないことをテストしてから再比較。 |
| P0 | **比較条件と指標が不足。** 画面の内蔵参考値は同じ6銘柄の端株買い持ちで、S&P500や日経平均ではない。 | 今回の指数参考値を評価の起点にし、次は投資可能な指数商品、円換算、配当・費用、現金比率を揃える。費用控除後リターン・最大下落・変動率・資金稼働率をセットで判定。 |
| P1 | **銘柄不足・偏りと100万円の単元制約。** 資金が余っても候補が買えず、最近は米テック3銘柄。 | 当時の投資可能銘柄集合に拡張し、購入可能率と業種・国・通貨・相関上限を設定。ETFは商品別の売買単位を使う。損失枠を上げて無理に買わせず、予算内で候補が確保できるか事前検証。 |
| P1 | **MA20/60と20日騰落率は似たトレンド情報。** 条件を外れるたび全売却し、横ばいで往復しやすい。5年244約定、手数料等約6.38万円＋スリッページ概算1.72万円。 | 週次判定、参入・退出の緩衝帯、ボラティリティに応じた配分を個別の改善候補として比較。後付けで最良値だけを採らず、近隣パラメータと未使用期間、費用増加でも改善が残る案だけ採る。 |

| P1 | **配当、税金、USD現金、流動性、分割処理が簡略。** 研究runnerの分割補正が通常CSV運用と共通化されていない。 | 配当・分割を資産台帳で処理し、商品マスターに実際の売買単位を持つ。楽天の取扱商品・決済通貨・料金で費用を再現。出来高/約定不能/価格急変の制約と、口座条件を揃えた税引後比較を追加。 |

## 次の採用判断

最初に時刻とデータを直し、次に資金100万円で実際に買える投資対象を設計し、改善候補を固定した未使用期間で比較する。投資可能な指数商品＋現金と同程度のリスクで、費用控除後の収益または下落抑制を再現して改善できるかを採用基準とする。基準を満たさなければ、個別株自動売買を主力にせず、広域指数商品を基本とする案を検討する。

10年100倍に必要な年率約58.5%を、今回の年率約7.76%は裏付けない。モンテカルロの年率8%/12%は入力仮定で、この戦略から推定した期待リターンではない。

## データ・再現方法

前回の戦略データは2026年10月23日、指数は10月24日に取得。すべて2026年10月22日までに固定。ローカルの価格列・原文はGit管理しない。[比較要約JSON](benchmark-review-2026-10-24-summary.json)に端点、ドル円、収益・下落、診断値、取得URLと原文SHA-256を保存。

データ：[S&P500履歴](https://finance.yahoo.com/quote/%5EGSPC/history/)、[日経平均履歴](https://finance.yahoo.com/quote/%5EN225/history/)、[ドル円履歴](https://finance.yahoo.com/quote/JPY%3DX/history/)。日足・単一為替レートの近似とデータ遡及訂正があるため、精密な実運用成績ではない。
