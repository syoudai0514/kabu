# v2検証プロトコル（結果を見る前の固定）

固定日：2026-10-24。500普通株版は、当時の投資可能集合・企業行動・売買単位を含む履歴データが未取得。現存銘柄を過去に当てはめて代用しない。

## 今回実装する共通ルール

- 初期JPY 1,000,000、積立・借入・空売りなし。開始日は2016/2021/2025-10-24、評価日は2026-10-23。
- UTC時刻順に価格・為替・企業行動を処理。注文は判断より後の当該銘柄の始値で約定。他国の未到来始値は使わない。日次為替しかない参考データでは、取引日の翌々日00:00 UTCに初めて利用可能とする保守的な遅延を置く。これは当時既知の為替による近似であり、実時刻の約定為替ではない。
- 毎月初めに、前月までに利用可能な完全な銘柄表から候補を選ぶ。252本以上の履歴、過去60本の売買代金中央値：日本1億円/日、米国100万USD/日以上。各国250候補を目指し、大型125・中型125、業種ごと最大50を売買代金順に選ぶ。不足は記録し、閾値を緩めない。時価総額帯・業種・単元は当時のマスターに依存する。
- 改善候補は金曜終値で判断（休場の週は判断を省略）。買いは終値>200日平均、50日平均>200日平均、126日リターン>0。売りは終値<200日平均、63日リターン<0、候補除外のいずれか。参入条件と退出条件を分ける。現行MA20/60は同じエンジンの比較モードに残す。
- 高リスクの既存想定損失枠2%と損切り幅15%を維持し、1回の購入予算は資産×min(15%,2%/15%)×0.97。単元を守り、買えない理由を記録。1銘柄15%、株式90%、1国60%、普通株の1業種30%、想定損失合計8%を上限。終値で15%損切り、口座最高値から40%下落で新規買付停止し売却。これらは翌始値ギャップによる損失を保証しない。
- USD現金を保持し、必要時のみ円転・ドル転する。手数料10bps、スリッページ5bps、通貨転換10bps。単元・資金不足・比率超過による注文拒否は記録する。
- 出来高参加率は、注文時点で既知の過去20日平均出来高の1%まで。分割時は保有数量・取得単価・指標用の過去価格・未約定数量を同時処理。配当は権利落ち時の保有者に未収計上し、既知の支払時刻に現金化する。支払日がないデータを自動的に権利落ち日に再投資しない。

## データ不足時の参考検証

2016年以前から存在する指数ETF 5本（1348.T=TOPIX、1346.T=日経225、SPY=S&P500、QQQ=NASDAQ100、IWM=米小型株）の固定集合だけで、エンジンとルールの参考値を計算する。JP 2本・US 3本は500普通株の代替でも、当時の最適商品選択の再現でもない。現在選んだETFの選択・生存者バイアスは残る。ETFには業種分散の透過データがないので普通株の業種上限を適用しない。ETF同士の重複も残る。

データ品質による事前変更：初期候補1306.T/1321.Tは、取得した日足に10倍/100倍の異常不連続と分割イベントの不整合があり隔離した。売買成績を計算する前に同じ指数の1348.T/1346.Tへ変更。異常値を推測で書き換えていない。

実装検証中の訂正：1348の売買単位は固定10口ではなく、[JPXの通知](https://www.jpx.co.jp/news/1030/20251002-01.html)に従って2025-10-16から1口に変更する。最初の試行後にこの事実を確認し、単元イベントを追加して全期間を再計算した。1346は[公式概要](https://www.jpx.co.jp/equities/products/etfs/issues/files/1346-j.pdf)の1口を用いるが、全期間の単元変更履歴を網羅した独立監査は未実施。開始時刻と寄り付きが一致する注文はその寄り付きでは約定させず、次の取引日の寄り付きを待つ。同時刻の全始値を評価に反映後、注文作成順（市場内のシグナル順位）で資金を配分する。これらは利回り最適化ではなくデータ・約定処理の訂正。

Yahoo日足の始値・終値・出来高と分割を使い、ETFの分配金・税・現金利息を除く。通常の配当込み総収益は計算できない。一般的なETFの売買条件による参考値で、楽天の取扱・実コストを確認済みとはしない。500株版の配当込み評価には支払時刻付き企業行動が必要。

ルールの変更・パラメータ探索を結果を見て行わない。3期間は同じ終了日の入れ子であり、未使用3標本とは呼ばない。2016以降の過去検証も現在作った規則による後知恵の診断。5本等金額買い持ち・国別代表ETF買い持ちを同じ価格・単元・コストで比較する。費用2倍と為替追加1日遅延でも再計算し、単独の良好な数字で採用を決めない。

## 採用判定

500株版の採用は保留。完全なPITデータを入れた後に、期間を前向きに分けて設定を固定し、複数開始月・相場局面・銘柄除外で確認する。同等リスクの指数＋現金に対して費用控除後の改善が残り、特定の業種/銘柄だけに利益が集中せず、日次ペーパー照合が通ることを採用条件とする。今回の参考値を目標利回りや将来予測に使わない。
