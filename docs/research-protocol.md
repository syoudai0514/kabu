# 大規模戦略探索の固定プロトコル

2026-10-24、初回探索結果を見る前に固定。目的は将来のS&P500超過収益につながる仮説を検証すること。過去の最良値や1年・5年・10年の勝利から将来の期待値を保証しない。

## 研究と採用を分ける

1. 同一データ・コスト・期間・通貨を固定して、24,000通りの一意な候補を再現可能に探索する。候補の生成・評価はPythonで行い、LLMを1試行ごとに呼ばない。
2. 2016-10-24〜2020-12-31を学習、2021-01-01〜2024-10-23を選別に使用。初期252本以上を指標計算に使う。順位はこの2期間だけで確定する。
3. 2024-10-24〜2026-10-23は順位付けから隔離した監査期間。既に会話・前の検証で見た期間なので、完全な未使用データとは呼ばない。監査結果を見て再探索すれば、監査期間も開発データになる。
4. 10年・5年・1年（各年10月24日開始〜2026-10-23）の結果は診断として併記する。この3つは重複し学習・選別期間を含むため、これらをすべて上回るまで繰り返すことを採用条件にしない。
5. 全候補の設定・不採用を含む指標・入力ハッシュ・試行数・シードを保存する。検証条件を変える研究は新しい実験として記録し、好結果だけを残さない。

## 今回の探索範囲

対象は固定5指数ETFの動作検証。日本・米国各250普通株の過去集合は未取得。5ETFの成績から500銘柄版の成績や個別成長株の発見能力を推定しない。指数ETF同士の構成銘柄の重複も残る。

トレンド・モメンタム期間、順位で選ぶ本数、リバランス間隔、投資比率、均等/変動率に応じた配分、目標変動率、SPYのトレンドによる現金退避、参入バッファを組み合わせる。探索範囲・採点式の実際の固定値は `research/search-space.json` と `scripts/research_search.py`。信用・借入・空売りなし、合計投資比率100%以下。

高速探索はUTC日次終値に揃えた連続比率モデル。翌日以降に反映するシグナルと遅延FXを使用し、同じモデルのSPYを基準とする。これは整数株数・実市場の寄り付き・国別休日・板・配当込みの実行可能なバックテストではない。探索上位候補は、そのまま実運用に昇格させない。

## 選別と分析

学習・選別の超過年率、最大下落、年ごとの安定性を確認する。最高リターンだけで選ばず、2倍コスト、近傍パラメータ、分割期間、候補全体の分布を併記する。選別で使った期間を検証済みの外部標本として扱わない。多数の候補の最良値には選択による上振れがあるため、通常の単一検定の信頼区間から優位性を断定しない。

最終分析は主担当が行い、Sol等の試行担当は同じCLIを実行する。担当モデル名を変えても乱数・データ・設定が同じなら同じ結果になる。外部LLMサービスのAPIキー・有料呼出しは不要。

## 運用への移行条件

研究結果には候補ID・設定・データハッシュと採用判定を付ける。固定ETF・高速近似・既知の監査期間である今回の結果は必ず `research_only` とする。採用失敗も正常な結果であり、無理に銘柄やリスクを変えて合格させない。

500銘柄版の正式なペーパー採用には、当時の銘柄集合を検証した実データ、整数株・翌寄り・為替・企業行動の詳細再生、日米をまたぐ業種と通貨リスクの照合、固定後に集めた未使用期間の結果が必要。実株の発注にはさらに証券会社の正式接続・注文照合が必要で、今回作成する機能には含まない。

今回作るモデル台帳と仮想配分計画は研究用であり、既存アプリの自動売買や楽天口座に研究上位候補を自動反映しない。スマホには試行数、S&P500比較、採否、未検証事項を表示する。
