# 無料版・現在の監視候補選定：事前固定条件

2026-10-25。個別株の価格取得・選別結果を見る前に固定する。[設定](../research/free-universe-policy.json)が実行条件。

目的は日米各250銘柄の**暫定監視候補**を作ること。収益率を最適化する実験ではなく、10年バックテストや本番採用の根拠にはしない。

- 取得済みのJPX月末・Nasdaq現在の一覧から、普通株候補を抽出。各ソースの最新成功バッチを固定し、将来取得した一覧へ途中で変更しない。
- 取得量を抑えるため各国最大1,000銘柄を価格取得対象にする。`SHA256(seed + ':' + market + ':' + symbol)`の昇順で抽出し、成績・知名度を使わない。全市場の流動性上位とは呼ばない。母集団・除外・抽出件数を記録する。
- 価格は公開チャート応答を研究用に取得・キャッシュ。YahooのCSVダウンロード機能とは別で、公式保証のある無料APIとは扱わない。取得が拒否されたら停止し、認証・課金への移行や制限回避はしない。応答原文は公開しない。
- 2025-01-01〜2026-10-23の完了日足を用いる。252本以上、最終日一致、直近60本の正の出来高90%以上、直近の日付間隔14日以内が条件。
- 流動性は直近60本の`終値×出来高`の中央値で近似し、日本1億円・米国100万ドル以上。改訂・分割調整済みの価格なので約定可能な真の売買代金ではない。直近60本に分割がある銘柄と、不連続警告がある銘柄は除外して照合待ちにする。
- 通貨・取引所・証券種別が取得元と一致しない応答を拒否。欠損は埋めず、失敗・警告・データ不足を個別保存する。
- 適格銘柄を流動性順・同値なら銘柄コード順に並べ、200/250/300の候補を作る。日本は既知の33業種につき50銘柄まで。米国の業種・規模は未確認なので分散条件を満たしたと扱わない。大型125/中型125の構成も未達として明記する。
- 必要数に届かない場合も閾値や抽出シードを変更せず、不足数を報告する。分割のない高流動性銘柄を優先すること自体の偏りも残る。

現在の一覧を過去の投資対象へ遡及適用しない。候補の利用開始は一覧と価格が揃った取得後。上場廃止、恒久ID、楽天取扱、当時の単元、企業行動の完全性、米国の業種・規模は未確認。これらの検証と時刻順再生へ接続する前に、株式売買や500銘柄での検証を完了したと表示しない。

価格に関する公式参考：[Yahooの履歴画面・有料CSV機能](https://in.help.yahoo.com/kb/finance/download-historical-data-yahoo-finance-sln2311.html)、[調整終値](https://in.help.yahoo.com/kb/finance/adjusted-close-sln28256.html)。今回の流動性計算には配当調整終値を使わない。今後の安定した日次運用にこの取得先が利用できることは未確認。
