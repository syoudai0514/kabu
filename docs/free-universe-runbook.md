# 無料の価格・流動性で現在の監視候補を作る

事前固定した[選定条件](free-universe-protocol.md)で、日米各1,000銘柄の抽出・価格取得・品質検査・各200/250/300候補の選別を実行するCLI。データ購読や外部LLM APIは不要。現在の普通株候補を対象とする参考スクリーニングで、過去の500銘柄バックテストではない。

## 実行と再開

先に[無料一覧取得](free-data-runbook.md)を実行する。必要ライブラリは一覧Excelの読み取り用で、価格取得と候補選定はPython標準ライブラリのみ。

```sh
python scripts/fetch-free-data.py
python scripts/select-free-universe.py --output research/history-free-universe-new
# 途中停止後も同じコマンドで未処理分のみ再開
python scripts/select-free-universe.py --output research/history-free-universe-new
# 小規模な接続確認（未処理分から日米交互に12件）
python scripts/select-free-universe.py --output research/history-free-universe-pilot --limit 12
# 完了した結果を通信なしで再計算・照合
python scripts/select-free-universe.py --output research/history-free-universe-new --offline
```

同一保存先へ複数プロセスを起動しない。途中停止でキャッシュの原文・メタ情報の片方だけが残る場合は整合性エラーとして報告される。破損したデータを自動で成功扱いしたり、ハッシュを無視して再利用しない。新しい実験ディレクトリで正常なキャッシュのみ引き継ぐ。

チェックポイントの最終行が書き込み途中で切れた場合は、その断片を`.incomplete-<hash>.bin`へ退避し、完了済み行から再開する。改行まで書かれた壊れた行や途中の破損は自動で捨てずエラーにする。

最大3ワーカー、各取得の後に待機を入れる。価格取得は最大3試行、HTTP 403/429では追加試行をせず全体を停止する。既に通信中の最大3件は終了し得る。制限を受けた実験の通信再開は拒否し、別ホストや偽装認証で回避しない。通信停止時は未処理数を残す。

失敗した銘柄は記録され、通常の再開で自動的に再取得しない。一時エラーを再調査する場合も古い失敗を残し、原因と取得条件を確認して別実験にする。`--offline`で未取得銘柄を処理するとキャッシュ不足を失敗として記録するため、原則として収集完了後に使用する。

## 保存物

- `manifest.json`：一覧のバッチ・取得時刻・原文ハッシュ、固定シードと設定、抽出した銘柄、母集団件数。途中で一覧が更新されても同じ実験では差し替えない。
- `engine-sha256.txt`：取得・選定・再開処理のコード4ファイルのハッシュ。コード変更後は同じ実験を上書き再開できない。
- `prices/`：銘柄・国・開始日・終了日の組ごとの原文とメタ情報。再取得せずハッシュを検証して使用。初回取得時刻を固定し、後日の再生で当時未完了だった日足が利用可能に変わることを防ぐ。
- `checkpoint.jsonl`：全処理銘柄の品質検査、流動性近似値、採否理由、エラー。1銘柄ごとに追記し、成功だけを残さない。
- `summary.json`：国別件数、理由別除外数、各200/250/300の候補一覧・不足数。理由は複数該当するため除外理由件数の合計が除外銘柄数を超える場合がある。

生データと詳細な銘柄一覧は既定の`research/history-*`以下に保存し、公開GitHub・静的サイトへは送らない。集計結果と限界を`reports/`へ保存する。スマホの既存研究画面への自動同期は今回の対象外。

## 解釈

候補が250件揃っても、250銘柄を保有・売買する意味ではない。現在の一覧は有名企業だけの固定6銘柄から対象を広げる入口にはなるが、過去の上場廃止・銘柄変更を再現していない。米国の業種・規模、歴史的な単元、楽天取扱、発注可能数量も未確認。

この段階の順位は流動性だけで、期待収益率や「10年で100倍になりそうな順」ではない。現在の業種分散や価格の品質を改善した後に、既存の戦略研究と詳細約定エンジンへ接続する。その際も、現在の候補で過去を検証した結果は生存者バイアスのある参考値と明示する。
