# 異なる売買思想を比較する第2実験

固定日：2026-10-24。初回の24,000候補は主にトレンド＋モメンタムのパラメータ違いであり、アルゴリズムの多様性が不足していた。利用者の指摘に従い、仕組みの異なる系統を比較する。

## 比較する9系統

| 系統 | 何を根拠に買うか | 主な弱点の仮説 |
|---|---|---|
| 順張り・相対順位 | 長期平均を上回り、過去リターンが強い対象 | 横ばいで往復売買、反転への対応が遅い |
| 終値レンジ突破 | 過去の終値上限を超えた対象を保有し、下限割れで退出 | だましの突破と急反落 |
| RSI逆張り | 短期の売られ過ぎからの回復を狙う | 下落トレンドで連続損失 |
| 短期の相対逆張り | 直近で相対的に下落した対象を買い、定期入替 | 弱い銘柄がさらに下落する局面 |
| 低変動率への配分 | 値動きの小さい対象を選び配分する | 強い上昇局面の収益不足、相関の上昇 |
| 複数期間モメンタム | 短・中・長期の騰落率を組み合わせ、弱い時は現金 | 局面変化で過去の強さが持続しない |
| SPY基礎配分＋追加戦略 | SPYを中心に持ち、一部を相対的に強い対象へ配分 | 追加戦略が基礎配分の収益を下げる |
| SPYの変動率管理 | 銘柄選択はせず、SPYの投資比率を調節 | リスク縮小後の急反発を取り逃す |
| 複数戦略の合成 | 順張り・逆張り・低変動率などの目標配分を合成 | 構成戦略の相関が高いと分散にならない |

ブレイクアウトは入力に高値・安値がないため、**終値**の過去上限・下限を使う。RSIの退出や保有期間は日次モデルの判断規則。財務指標やニュースを使った戦略は、時点整合した入力がないため、試したと偽らない。

各系統に同程度の探索予算を割り当て、設定ハッシュ・全候補・不採用も保存する。系統数とパラメータ試行数を別々に表示する。異なる設定で同じ売買になる場合があり、試行数を独立した戦略数や証拠の数に読み替えない。

## 評価の固定

前の研究と同じ固定5ETF、円、費用、信用なし、連続比率の日次近似で比較する。学習2016-10-24〜2020-12-31、選別2021-01-01〜2024-10-23。順位付けはこの2期間だけ。監査2024-10-24〜2026-10-23、10/5/1年の資産額、費用2倍は診断に用いる。

**全期間が既知の開発データである。** 前の研究で結果を見た後に系統を拡張したため、監査の完全未使用性はない。選別後に見つかった最高値を将来の期待値と呼ばない。

各系統の最上位候補を同じS&P500基準で並べる。評価項目は学習・選別の超過年率、最大下落、回転・費用、監査での劣化、10/5/1年診断。特定ETFを候補から除いた場合も確認するが、除外結果を見て順位を最適化しない。

第1実験の台帳を上書きせず、`research/history-families-2026-10-24/`に別実験として保存する。新しい探索範囲の実値は`research/family-space.json`。初回研究と同様、固定ETFの高速近似なので合格が出ても自動採用しない。

日本・米国各250普通株のデータ取得と高速探索への対応、整数株と実市場時刻での詳細再生は別の未完了項目。今回の9系統比較を500銘柄版の検証と表現しない。
